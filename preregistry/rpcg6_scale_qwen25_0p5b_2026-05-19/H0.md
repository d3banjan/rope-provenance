# H0 — rpcg6_scale_qwen25_0p5b — 2026-05-19

> Pre-registration. Frozen before any model load. Scale check of RPCG3.

## 0. Context

RPCG3 returned `GATE_INSTALLED` on Pythia-70m: a DPO + chosen-NLL anchor adapter
installs a role-conditioned capability gate. RPCG6 asks whether that result is a
Pythia-70m artifact by re-running the **identical RPCG3 recipe** on
**Qwen2.5-0.5B** — a Llama-style architecture (split q/k/v projections, GQA,
gated SwiGLU, RMSNorm) at ~7× the parameter count, and the model the LRS1
geometry baseline was measured on.

Only three things change vs RPCG3, all forced by the model: the base model
(`Qwen/Qwen2.5-0.5B`), the LoRA target (`q_proj,k_proj,v_proj` — Qwen splits the
QKV that GPT-NeoX fuses into `query_key_value`), and the working dtype
(`bfloat16` — Qwen-native; fp32 risks OOM on a 12 GB card, fp16 risks NaN). The
corpus, the 3-arm structure, the DPO+anchor objective, all hyperparameters
(β=0.1, anchor λ=1.0, LoRA r=8 α=16, 900 steps, lr 2e-4 pretrain / 3e-4 DPO,
seed 42), the probe, the decision rule, and every τ are **identical to RPCG3**.

## 1. Obstacle-class pre-flight

**Risked class: NEW** — role-conditioned capability gate (same class as RPCG3).
RPCG6 is a cross-architecture / scale replication; it does not test a new
mechanism. Class-K note: logit-level (bias-path) probe; v1 claim scoped
accordingly — no free-generation claim (that is RPCG8).

## 2. Hypothesis

- **H0 (null):** the RPCG3 gate is Pythia-70m-specific — on Qwen2.5-0.5B the
  same recipe does not install a role-conditioned gate (gated Δ ≤ τ).
- **H1 (alternative):** the gate replicates across architecture and scale —
  gated Δ > τ, ≥ 8/9 sign-correct, role-swap trap collapses.

## 3. Decision rule

Identical to RPCG3 `H0.md` §3 (reused `<monorepo>/scripts/decide.py`). Per-cell shift, signed
shift, gate margin Δ, τ = 3 × stdev(null per-cell signed shifts). Verdicts
**GATE_INSTALLED / GATE_PRESENT_NOT_LOW_RANK / NO_GATE / INCONCLUSIVE_WEAK_SIGNAL
/ VOID**. Tie-break: VOID dominates, then INCONCLUSIVE over NO_GATE.

## 4. τ (frozen pre-run)

See `tau.json` — values identical to RPCG3, hash differs (experiment name).

## 5. Matched null / 6. Trap

Unchanged from RPCG3. Null = tag-only DPO arm (balanced ordered pairs → no net
preference → Δ ≈ 0, defines τ). Trap = role-swap DPO arm (cyclic-shuffled map);
probed against the true map Δ must collapse. Trap Δ > τ → the gated margin is
not role-specific (VOID).

## 7. Source / sites

`Qwen/Qwen2.5-0.5B` base, 24 layers. LoRA r=8 α=16 on `q_proj`, `k_proj`,
`v_proj` (all layers). bf16. Continued-pretrain: full fine-tune (the 6 added
annotation-token embeddings must train). DPO β=0.1 + chosen-NLL anchor λ=1.0,
900 steps, reference via PEFT `disable_adapter()`. Probe site: the open-token
slot after each role+frame prefix.

## 8. Readouts

Primary: gate margin Δ over the 5 training frames. Secondary: held-out-frame
margin. Geometry: gated adapter mean stable rank vs the LRS1 Qwen DPO reference
(~3.8). Quality gate: DPO convergence.

## 9. Wall-time budget + run-time discipline

Qwen2.5-0.5B, bf16, RTX 3060 12 GB. Estimated wall ≈ 30–45 min (full-FT
continued-pretrain + 3 DPO runs × 900 steps + 4 probes). Progress flushed.
`tau_sha256` in `decision.json` and the artifact.

**OOM contingency:** if the full-FT continued-pretrain exceeds 12 GB, the
fallback is 8-bit Adam (bitsandbytes `adamw_bnb_8bit`) for the pretrain
optimizer, recorded as an amendment (analogous to LRS1 `amendment_01`). bf16 +
fp32 AdamW states for 0.5B is projected at ≈ 6 GB and expected to fit; the
amendment is the documented escape if the projection is wrong.
