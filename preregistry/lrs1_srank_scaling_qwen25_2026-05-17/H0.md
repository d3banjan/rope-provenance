  verdict*, not a KILL/SHIP.
- **What could still go wrong** (methodology, not mechanism):

- **Named architecture contrast under test:** GPT-NeoX (fused
  `query_key_value`, parallel attention+MLP) → Llama-style (split
  q/k/v/o_proj, GQA, gated SwiGLU MLP, RMSNorm). The question is whether the
  flat srank floor is a property of preference-learning geometry or an
  artifact of the GPT-NeoX block.

## 2. Hypothesis (H0 vs H1)

Measured quantity: `attn_qkv_srank(d)` — the arithmetic mean of stable rank
`‖ΔW‖²_F / σ²_max` over the attention QKV input-projection LoRA adapters
(q_proj, k_proj, v_proj; all layers) of a DPO run, for each model size
`d ∈ {896, 1536, 2048}` (= d_model of Qwen2.5 0.5B/1.5B/3B).

> **Metric note (V1-informed).** lazy-rudder's published "task-intrinsic
> srank ≈ 3.653" is the stable rank of the attention QKV input projection
> ONLY (Pythia's fused `query_key_value`). Confirmed against
> the lazy-rudder spectral-autopsy results (research monorepo, v2_dpo_r128):
> the 4-module global mean is 5.197, the `query_key_value`-only mean is 3.924.
> The Qwen-comparable floor metric is therefore the q/k/v_proj mean, not the
> 7-module global mean. `global_srank` (all 7) and `q_proj_srank` are still
> computed and shipped as secondaries.

- **H0 (architecture-sensitive):** the flat srank floor is a GPT-NeoX artifact.
  On Qwen2.5 the srank scales with width — a `c/√d` or `c/d^⅓` fit beats the
  constant fit by `ΔAIC(constant) ≥ 2`, OR an `attn_qkv_srank` falls outside
  `[2.5, 5.0]`.

- **H1 (task-intrinsic):** the flat floor survives the architecture change.
  The constant fit wins or ties (`ΔAIC(constant) < 2`) AND all three
  `attn_qkv_srank ∈ [2.5, 5.0]` AND the max−min spread `< 1.5` — consistent
  with the lazy-rudder reference `3.653 ± 0.289 RMS`.

Both stated falsifiably. The verdict is genuinely two-sided: prior literature
gives a *scaling* prior, not a flat prior.

## 3. Decision rule

> Frozen. No editing after the run starts.

Fit the 3 points `(d, attn_qkv_srank)` to three 1-parameter models, `c` by
least squares in each model's natural parametrization:

- **M0 constant:** `srank = c`
- **M1 acoustic:** `srank = c / √d`
- **M2 cube-root:** `srank = c / d^⅓`

`RSS_M = Σ (srank_i − f_M(d_i))²`; `AIC_M = n·ln(RSS_M/n) + 2k`, `k=1`, `n=3`.
The small-sample AICc correction `2k(k+1)/(n−k−1) = +4` is identical for all
three models and cancels in `ΔAIC`. `ΔAIC(M) = AIC_M − min_j AIC_j`.

- **REPLICATES_FLAT_FLOOR:**
  `ΔAIC(M0) < 2` (constant wins or within decisive distance)
  ∧ all three `attn_qkv_srank ∈ [2.5, 5.0]`
  ∧ `max(srank) − min(srank) < 1.5`.

- **ARCH_SENSITIVE_SCALING:**
  a scaling model (M1 or M2) wins with `ΔAIC(M0) ≥ 2`
  ∧ the winning fit predicts a monotone width trend.

- **INCONCLUSIVE_THIN_DOF:**
  no model separates from the others by `ΔAIC ≥ 2`, and the robust band
  criterion (sranks in `[2.5,5.0]`, spread `< 1.5`) is not cleanly met.

- **ESCALATE_TRAINING_PATHOLOGY:**
  any NaN/inf in a training loss after grad-clip=1.0 + warmup, OR V1 (§6)
  reproduction off by > 5%.

- **Tie-breaking:** ESCALATE_TRAINING_PATHOLOGY > ARCH_SENSITIVE_SCALING >
  REPLICATES_FLAT_FLOOR > INCONCLUSIVE_THIN_DOF.

**Primary vs secondary.** With n=3, AIC *ranks* models, it does not *test*
them. The **primary, robust verdict is the band criterion**: all three
`attn_qkv_srank` in `[2.5, 5.0]` with spread `< 1.5`. The ΔAIC test is reported
as a secondary, explicitly underpowered discriminator. See `power.md`.

## 5. Trap / matched nulls

This is a measurement probe; the "nulls" verify the kernel discriminates
structure from noise rather than a behavioural trap.

| Null | Construction | What it proves |
|---|---|---|
| synthetic random adapter | random Gaussian B@A at r=128, correct Qwen keys | a structureless adapter must read srank ≫ floor (order tens) — the kernel is not biased low |
| synthetic low-rank adapter | B with only the top-3 columns non-zero | kernel returns srank ≈ 3.0 ± 0.3 on a known target |
| analytic random baseline | closed-form `E[p(k)] = k/d` per module | matched reference for the random-overlap floor |

If the synthetic random adapter reads a low srank, the kernel is broken and the
run halts — no Qwen number is trusted.

## 6. V1 validation gate (pre-GPU)

Before any Qwen training, the O1 QR-reduce srank kernel is run on a **real
lazy-rudder Pythia-410M DPO r=128 adapter** (`d3banjan/lazy-rudder-checkpoints`
on HuggingFace; GPT-NeoX key template). It must reproduce lazy-rudder's recorded
stable rank — the `query_key_value`-module mean 3.9244 AND the 4-module global
mean 5.1968 (`<monorepo>/...` spectral-autopsy results, v2_dpo_r128) — each within
`v1_repro_tolerance_pct = 5%`. This proves the kernel and the arch port are
lossless against the reference. V1 failure → no GPU spend.

> V1 outcome (2026-05-17): **PASS** — measured 3.9244 / 5.1968, both rel 0.001%.
> V1 also surfaced the metric correction recorded in §2.

- **Sizes:** Qwen2.5-{0.5B, 1.5B, 3B} base. One seed (42).
- **Recipe = lazy-rudder verbatim, one deviation.** LoRA r=128, α=256,

- **Target modules (7):** q/k/v/o_proj, gate/up/down_proj.
- **Checkpoints:** adapter-only, every 100 steps (8 per run).
- **Tokenizer:** Qwen base — no chat template (raw hh-rlhf text); pad_token
  distinct from eos `<|endoftext|>`.
