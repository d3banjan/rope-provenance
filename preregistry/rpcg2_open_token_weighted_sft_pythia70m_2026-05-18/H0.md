# H0 — rpcg2_open_token_weighted_sft_pythia70m — 2026-05-18

> Pre-registration. Frozen before any model load. Escalation rung 1 of RPCG1
> (`preregistry/rpcg1_capability_gate_pythia70m_2026-05-18/`).

## 0. Escalation context

RPCG1 returned **VOID**: positive-only LoRA-QKV SFT with a plain causal-LM loss
did not fit a role-conditional permitted set on Pythia-70m. Diagnosis (RPCG1
postmortem): the LM loss is dominated by body tokens; the open-token decision
slot is ~1 of ~25 tokens/doc, so the loss is satisfiable by the SFT marginal
without using the role. The `gated` and `trap` arms were marginal-identical
(mean |Δ| = 0.0044).

**RPCG2 changes exactly one thing:** the SFT loss is masked to the open-token
slot. Cross-entropy is averaged ONLY over positions whose causal label is a
primitive open token (`<|exec|>` / `<|net|>` / `<|sys|>`). The gradient is forced
through the role → primitive decision. Corpus, continued-pretrain, the 3-arm
structure, the probe, the decision rule, and every τ are **identical to RPCG1**.

## 1. Obstacle-class pre-flight

**Risked class: NEW** — role-conditioned capability gate (unchanged from RPCG1).
RPCG2 removes the Class-I methodology wall that VOIDed RPCG1 (a too-weak SFT
objective). With the open-token-masked loss the SFT objective *directly demands*
the role-conditional fit, so a VOID/`NO_GATE` here is mechanism-relevant, not a
recipe artifact.

Class-K note: the probe is a logit-level (bias-path) readout; the v1 claim is
scoped to the logit-level gate, no free-generation claim (unchanged from RPCG1).

## 2. Hypothesis

- **H0 (null):** even with an open-token-masked SFT loss, positive-only SFT does
  not suppress out-of-role primitive logits beyond the tag-only-null floor —
  gated-arm gate margin Δ ≤ τ.
- **H1 (alternative):** the open-token-masked SFT installs a role-conditioned
  gate — gated-arm Δ > τ, ≥ 8/9 sign-correct, role-swap trap collapses.

## 3. Decision rule

Identical to RPCG1 `H0.md` §3 (reused `<monorepo>/scripts/decide.py`). Per-cell shift, signed shift,
gate margin Δ, τ = 3 × stdev(null per-cell signed shifts). Verdicts:
**GATE_INSTALLED / GATE_PRESENT_NOT_LOW_RANK / NO_GATE / INCONCLUSIVE_WEAK_SIGNAL
/ VOID**. Tie-break: VOID dominates, then INCONCLUSIVE over NO_GATE.

**Interpretation amendment (does not change the rule):** under the open-token-
masked loss the SFT objective directly optimizes the role-conditional decision.
Therefore:
- A `VOID` via Probe-2 fail now reads as a **capacity wall** — LoRA-QKV r=8 could
  not fit the role map even when the objective demanded it — not a recipe weakness.
- A `NO_GATE` (Δ ≤ τ, Probe-1 drop, Probe-2 pass) is a strong kill: the SFT fit
  the permitted set yet installed no role-conditioned suppression.

## 4. τ (frozen pre-run)

See `tau.json` — values identical to RPCG1, hash differs (experiment name).
Multipliers/margins frozen; the gate-margin τ number is data-derived (3 × the
null arm's per-cell signed-shift SD).

## 5. Matched null / 6. Trap

Unchanged from RPCG1. Null = tag-only arm (all 9 cells, open-masked loss → no
role→primitive suppression signal → Δ ≈ 0, defines τ). Trap = role-swap arm
(cyclic-shuffled map, open-masked loss); probed against the true map Δ must
collapse. Trap Δ > τ → halt, pipeline bug.

## 7. Source / sites

LoRA on the Pythia `query_key_value` fused module, all 6 layers, r=8, α=16
(unchanged — RPCG2 isolates the *objective*, not the capacity; capacity is the
RPCG4 escalation). SFT loss: `open_masked` (cross-entropy over open-token-label
positions only). Probe site: the open-token slot after each role+frame prefix.

## 8. Readouts

Primary: gate margin Δ over the 5 training frames. Secondary: held-out-frame
margin. Geometry: gated adapter mean srank vs LRS1 ≈ 3.8. Quality gate: SFT
convergence (Probe-2).
